# Step 5 research: Belleville Set 1

## Scope and source basis

This first research batch covers the ten scheduled lines in Set 1, used by door 100A. It compares manufacturer specifications for exact model tokens where available. Catalog mappings remain candidates until a reviewer confirms that the schedule's prefixes and options match the selected product records.

Door 100A is listed as an exterior pair door, 965 mm wide per leaf, 2134 mm high, 57 mm thick, aluminum, with LHR/RHR handing and no fire rating shown. The schedule places Set 1 on PDF page 26. A blank fire-rating field means “not stated,” not confirmation that the door is unrated.

## Current result

The source-backed checks improve determination for one specific interface (Camden activation switch to dormakaba operator) and one mounting pair (dormakaba closer to BP86 plate). They do not justify marking Set 1 as a fully compatible six- or ten-item assembly. The ABH chart also surfaces a potentially significant closer/holder interference that must be checked against the actual 38-inch continuous-hinge installation.

No item is automatically confirmed as a catalog match by this research. The existing `661HD CE-12` product is explicitly not used as a match for the scheduled standard `661HD` hinge.
