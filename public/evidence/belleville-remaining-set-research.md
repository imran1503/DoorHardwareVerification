# Step 5 research: Belleville remaining hardware sets

## Scope and method

This report covers the recurring hardware-set families after Sets 1 and 2, using the imported schedule, its continuation pages, and manufacturer documentation. Model mappings written to the catalog are **candidates** until a reviewer confirms the schedule finish, option suffix, prep and door conditions. A model fact or one supported component relationship is not a verdict that an entire set works.

The imported set data includes the door assignments and item lines, but opening dimensions and preparation are not populated in the local door records for the reviewed groups. Where a fit decision depends on those values, the result remains unverified.

## Database changes from this pass

- Added primary-source evidence links and scoped catalog records for documented models: QCL230/261/271, QED113, QET130, QDC311, BEST FBB179, dormakaba 662HD and 662HD CE-12, Gallery GSH80A/199B/209/401, Canaropa 3515 and M1800-1, and BEST BPC60-00-60.
- Generated **candidate** scheduled-item matches with the supporting evidence attached. These are not automatically confirmed product matches.
- Added one source-scoped pair assertion for the QED113/QET130 device-to-trim relationship. It is explicitly limited to that product-family relationship and its conditions.
- Added review notes for the repeated set families and left the whole assemblies unverified when model options, opening dimensions, prep, listings or wiring were not established.

## What the findings do not establish

They do not certify code compliance, fire-door listings, opening fit, installation quality, key-system authorization, or whole-assembly compatibility. A source describing a product or a two-product interface only supports the specific facts in that row. The complete per-set evidence trail is represented by this report and the manufacturer source links above.
