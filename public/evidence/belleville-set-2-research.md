# Step 5 research: Belleville Set 2

## Scope

This batch reviews the 17 scheduled lines in Set 2, assigned to door 100B. The schedule identifies 100B as a paired door, 965 mm wide per leaf, 2134 mm high and 45 mm thick, with LHR/RHR handing. The door-index fire-rating cell is blank, which means the schedule does not state a rating. Set 2 spans PDF pages 27–28; the operator/controller, access control and generic localized power supply appear on page 28. These schedule details are read from the imported Belleville schedule, not inferred from manufacturer material.

## Current result

Four narrow, two-product electrical/contact interfaces are now source-backed: CM-35N/4 to CX-33 input, CX-33 relay to ED100 X4, RCI 9540 to CX-33 input, and RCI 915 relay to CX-33 input. Each depends on installation wiring and/or controller configuration. They are not a compatibility approval for the complete Set 2 assembly.

The full group remains **unverified** until the MLR power supply and direct wiring, CX-33 operating mode, exact reader, mullion preparation, paired-leaf allocation, door/operator configuration, and field installation are resolved. Product matches added by this batch remain `candidate`; none are automatically confirmed.
